# Ortho preSSaleel – question bank

`questions.json` is the online question bank for the Ortho preSSaleel Android app (orthopaedic superspeciality prep: INI-SS, NEET-SS, FET).
The app downloads it on launch and adds any new questions. Questions are only ever appended, never reordered or removed, so saved progress on the phone stays valid.

Separate from OrthoQuest; nothing else in this repository uses this folder.

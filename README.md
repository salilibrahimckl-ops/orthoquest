# OrthoQuest

Orthopaedic surgery training game: real scan-based 3D anatomy, operations performed layer by layer (skin → fascia → muscle split / internervous plane → bone → implant), multiple standard approaches per operation, post-op viva questions, NEET-SS / FET MCQs and clinical cases.

Play: https://salilibrahimckl-ops.github.io/orthoquest/

Anatomy: BodyParts3D, © The Database Center for Life Science, licensed CC BY 4.0 (adapted: simplified, smoothed; peripheral nerves routed for teaching). Three.js © three.js authors (MIT). Educational use only — not a clinical tool.
